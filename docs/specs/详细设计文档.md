## 1. 概述

一个 Rust 桌面端 JSON 工具，核心能力：加载/输入 JSON → 格式化（含去转义、嵌套 JSON 自动展开）→ 双栏展示（JSON 树 + 高亮原文）→ 树原文双向定位 → 数组转表格 → 表格多值过滤 → 行转列。

**设计约束**：必须能流畅处理大 JSON（≥100MB）。所有性能策略围绕"前端只渲染可见数据、数据按需从 Rust 端获取"展开。

## 2. 技术栈

| 层 | 选型 | 理由 |
|---|------|------|
| 桌面框架 | Tauri 2 | 体积小，Windows 11 自带 WebView2 |
| 后端 | Rust + serde_json + 自研 span 解析器 | 解析性能与树→原文定位能力 |
| 前端 | Vue 3 + TypeScript + Vite | 生态成熟，虚拟化组件齐全 |
| UI 组件 | Naive UI + TanStack Virtual | 表格/树/右键菜单开箱即用，虚拟滚动 |
| 原文查看器 | CodeMirror 6 | 大文件虚拟滚动、行高亮 |
| 样式 | 手写 CSS（暗色/亮色双主题） | 自由度高，保证现代美观 |
| 国际化 | 自研轻量 i18n（`src/i18n.ts`） | `locale` 模块级单例 + `t(key, params)`，编译期校验中英字典 key 一致 |

- **Naive 组件层跟随主题**：App 根部 `<NConfigProvider abstract>` 统一注入 `darkTheme`/亮色默认 + 覆盖色值；表格、输入框、按钮、下拉、树不再回落浅色默认。

## 4. 功能设计

### 4.1 加载
- 拖拽 `.json` 文件到**窗口任意位置**（含编辑器/树面板，子组件放行文件拖放）即加载；支持「打开...」选择；**在可编辑原文中粘贴**文本（原生编辑器粘贴 → 防抖重解析）。
- 全局 paste 监听已移除（避免劫持输入框）。
- 状态栏大小显示：≤1024KB 用 KB（1 位小数），超过用 MB（2 位小数）。

### 4.2 格式化（span 保真 + 嵌套展开 · 2026-10-15 修订）
- 「格式化」按钮**单击立即执行**：固定 2 空格缩进，**span 保真——只重排空白，token 原样保留**（见 §4.11）；**字符串值内容本身是合法 JSON（对象/数组）时自动展开为真实结构**（cc.txt/ff.txt 场景，子树内部同样保真，`\uXXXX` 写法保留）；「压缩」输出单行 minified（不展开）。
- 整篇转义文档（`{\"a\": 1}` 形态）：格式化时先还原再保真重排。
- 格式化失败（严格与宽松均不合法）时：错误信息精确到行列，原文对应位置红色波浪线标记。

### 4.3 JSON 树 + 原文定位
- **原文可编辑**：编辑后防抖 500ms 自动重新解析，树/表格/状态栏联动刷新；非法输入显示错误行列与波浪线，不清空编辑器。程序性加载（格式化、打开文件）与用户编辑通过事务注解区分，防止光标跳动。粘贴整段文本有独立标记（CM `input.paste` 事务），供探测弹层与处理中蒙版区分「粘贴」与「打字」。
- 树节点：类型图标（📁对象/数组、📄值），数组节点显示 `[n]` 长度；长字符串截断显示；双击值复制。
- 树虚拟滚动：只渲染可见行；节点展开时才向后端请求子节点（懒加载）。
- 树 → 原文：Rust 端解析时为每个节点记录字节区间 span；点击节点 → 原文滚动到对应行并高亮闪烁。
- 原文 → 树：点击原文 key/value/括号 → 反查最内层节点 → 树中选中并**滚动到可视区**（NTree.scrollTo + 兜底）。
- **原文搜索框**（面板头右侧）：输入即时高亮全部命中 + `n/m` 计数，Enter/Shift+Enter 上下跳转，Esc 清除并还焦点，**Ctrl+F 聚焦搜索框**；有输入时显示 ✕ 清除。
- 树节点值**单行省略号**显示，悬停 title 显示完整内容。

### 4.4 数组转表格（任意节点）
- 右键**任意类型节点** → 「转为表格」：底部面板展开。数组 = N 行（每元素一行）；非数组（对象/标量）= 1 行（对象列为其字段，标量单列"值"）。
- 列 = 所有子元素对象的键并集（子元素非对象时退化为单列"值"）。
- 嵌套单元格右键支持下钻（内层数组/对象建为新表格，「← 返回」逐层回退）。
- 单元格显示**原始 JSON 内容**（嵌套对象/数组显示其原文切片，深入查看用行转列/下钻）。
- 表格虚拟滚动，行数据按需分块获取（`get_rows(offset, limit)`，**50 行/次**——2026-10-13 从 500 降档，大表渲染卡顿实测后调整）；过滤态命中行同款分块（先取前 50，「加载更多」按命中索引续块；状态栏注明已载行数）。宽匹配全量拉取会卡死主线程（9488 行 × 34 列实测）。
- **列宽自适应内容**（80-480px 夹紧），列少右侧留空不强制铺满；# 列 24px、居中、灰色。
- **列选择（Excel 式）**：左键点表头选列、Shift 范围、Ctrl 增删，选中列高亮；**行号点击选整行**（同款多选）。Ctrl+C 复制 TSV：行列都有 = 交集矩阵，只有行/列 = 对应 TSV（含表头，仅含已加载行）。
- **列显示筛选（2026-10-15 新增）**：工具栏「过滤列 n/m」按钮 → 浮层多选勾选要展示的列（>8 列时带列名搜索框，底部「全选 / 反选」；允许全不选——只剩 # 序号列，全选恢复）。**编辑作用于草稿，浮层收起时一次性提交**（面板开着时表格不跳动）。纯视图层：表格渲染/横向滚动宽度/TSV 复制范围均只含可见列，**导出 Excel 仍含全部列**；换表/下钻/重挂时重置。表头点击列映射、右键菜单列推断、命中列横向滚动均改用可见列集合。
- 同一面板一次展示一个表格（多表格 tab 切换为后续增强）。

### 4.4a 导出 Excel
- 表头「⬆ 导出 Excel」按钮 → 系统另存对话框 → Rust 端 `table_export` 写 .xlsx（rust_xlsxwriter）。
- **导出 = 当前筛选结果**（列过滤/多值过滤都生效）；数字写数值类型；带 autofilter 与列宽。

### 4.5 表格搜索过滤（**已确认：命中任一值即保留**）
- 表头上方单个搜索框（**自适应 textarea，支持多行输入**），输入多个值，分隔符支持：英文逗号 `,`、空格、Tab、换行。
- **列级过滤**：右键表头列 → 「只过滤此列」，搜索框显示列芯片（点击芯片取消，恢复全列）；未锁定时搜索所有列。
- 过滤规则：某行在搜索范围内**任一**单元格命中**任一**输入值 → 该行保留，命中处 ✓ 标记；嵌套单元格按其**原始 JSON 内容**匹配（key 与 value 都算，如搜 `address` 命中含 `"address"` key 的对象）。
- 匹配语义：**模糊匹配**——包含、忽略大小写（对象/数组匹配其原文切片，标量匹配字面值）。
- 输入防抖 500ms，过滤在 Rust 端执行（大数组不走前端遍历），返回命中的行索引集合。
- 过滤完成后**横向滚动自动定位到第一个命中列**（无命中/无横向溢出则不动）。

### 4.6 行转列（**本次新增**）
- 右键表格某一行 → 「行转列」：面板内切换为转置视图，两列显示：`字段名 | 值`，一行对象的所有字段纵向排列。
- 适用场景：字段很多的宽行，横看吃力，转成纵向逐字段查看。
- 转置表两列定宽（字段 240px / 值铺满），不受主网格列宽自适应影响。
- **统一「← 返回」按钮**（位于「⬆ 隐藏」右侧）：转置视图 → 返回主网格；下钻栈非空 → 返回上层表格；两者按优先级分发，都无则不显示。

### 4.7 表格面板生命周期（永不销毁）
- 面板组件常驻，状态机：`hidden`（默认，32px 细栏）/ `shown` / `restoring`；「⬆ 隐藏 / ⬇ 恢复」切换，**无删除路径**。
- 细栏三态文案：无文档 = `📊 表格 · 加载 JSON 后右键节点转为表格`（置灰、不可拖拽恢复）；有文档无表 = `📊 表格 · 右键树节点转为表格`；数据过期（编辑后）= `📊 表格 · 数据已过期，点击恢复`。
- 恢复时若 stale → 先 `table_reopen`（按 lastPath 重挂表格 + 重放过滤条件）再显示；path 失效 → 提示（黄色警告）并保持隐藏。
- 文档替换/编辑：面板可见时 revalidate（重挂 + 重放过滤）；隐藏时仅标记 stale。

### 4.8 处理中蒙版（2026-10-13 新增）
- 格式化/压缩/拖拽/打开/粘贴解析期间，树 + 原文双面板盖深色蒙版（琥珀旋转环 +「处理中…」），完成自动揭开；编辑器**打字不显示**（防闪烁）。
- 触发矩阵：格式化/压缩 ✅（点击 → 界面刷新完成）；拖拽/打开 ✅；粘贴 ✅（CM `input.paste` 标记 → 500ms 防抖 → 解析完成）；打字 ❌；过滤/搜索/表格 ❌。探测浮层点候选载入、「↩ 原始文本」切回也显示（真实解析工作）。
- `busyCount` 计数器（`panelBusy` 经 provide 注入），蒙版显示条件 = `busyCount > 0`；begin/end 三处所有者：RawView 的 doFormat/doMinify、App 的 loadTextInner（按调用类型）、`applyPreloaded` 收尾（try/finally 异常安全，蒙版不会滞留）。格式化/压缩按钮 busy 期间置灰。
- 样式：`rgba(10,12,15,.62)` 蒙版 + 26px 旋转环（0.8s）+ 12px accent 文字；z-index 500（低于探测浮层 1000、单元格气泡 900）；蒙版文字 `role="status" aria-live="polite"`；`prefers-reduced-motion` 下静态显示。

### 4.9 格式化链路提速（2026-10-13 新增）
- **消除重复 parse**：`format_text`/`minify_text` 成功时已将新文档 + span 树载入后端 state，返回 `already_loaded: true`；前端 `applyPreloaded` 直接用返回的 rootId 刷新，跳过第二次 `load_text`（省 ~108ms parse + 大文本 IPC 往返）。
- **消除 unwrap 双 parse**：format/minify 先直接解析原文，失败才走 `unwrap_escaped` 还原路径（合法文档省一次全文 parse）。
- `s.load` 失败不再静默吞掉（返回 Err）；命令层抽出可测核心（`format_text_impl`/`minify_text_impl`）+ 4 个单测。
- 实测（test.txt 9.5MB）：format 全程 212→175ms，端到端 1.0–1.3s → ~0.7–0.9s。
- 分阶段基准：`cargo test --release --test bench_format -- --ignored --nocapture`。

### 4.10 JSON 探测（2026-10-13 新增）
- **触发**：拖拽/打开/粘贴的文本解析失败时，`load_text` 同一请求内顺带探测（`detections` 字段随 DocInfo 返回）；编辑器打字/粘贴失败只静默更新入口，**不弹浮层**（防打断输入）。
- **探测管线**（Rust `detector.rs`，单遍 O(n)）：字符串字面量转义还原（逐层 ≤3，覆盖 `"{\"a\":1}"` 单双层转义）→ 字符串感知的顶层 `{…}`/`[…]` 结构扫描（字符串内假括号不算）→ 缺括号补全（行首 `"k": v` 键值对段包 `{}`、≥2 个顶层标量段包 `[]`，包裹后验证合法）→ 候选必须通过 parse 验证才入选。限额：候选 ≤50、扫描 ≤10MB（超出注明）。
- **UI**：居中浮层卡片列表（类型徽章 {}/[] + 行号/字符数/嵌套深度 + 语法高亮单行预览），点卡片载入 = 用片段文本（还原+补全后）替换整个文档，走正常加载链路；已载入卡片打 ✓。
- **会话**：候选 + 原始全文保留，状态栏双入口 `⚡ 探测结果 (n)`（重开浮层换选）/ `↩ 原始文本`（切回全文并自动重弹浮层，闭环）；载入新文档/清空时丢弃。
- 只报**顶层**片段（嵌套不单列）；无候选维持现状（错误行列 + 波浪线）。

### 4.11 宽松解析：单引号 / 裸键 / 尾逗号 / 裸值（2026-10-14 新增）
- **范围**：对齐 JS 对象字面量与 Python 字面量的常见写法——单引号字符串、裸键、尾逗号、无引号裸词值。**全局生效，无开关**：加载/树视图/格式化/压缩/表格/探测统一宽松；不支持注释、十六进制数字等其余 JSON5 特性。
- **语法细则**：
  - 单引号：键和字符串值均可用 `'...'`；`\'` 转义为引号本身，其余转义与双引号规则一致；`"` 在单引号串内、`'` 在双引号串内均为字面量。**`\'` 在双引号串内同样还原为单引号**（2026-10-15 放开，用户实测 `{"a":"{\'c\':\'b\'}"}` 需可解析）。
  - 裸键：JS 标识符风格 `[A-Za-z_$][A-Za-z0-9_$]*`，不允许空；裸键后无冒号时回退到裸键起点报错（与严格模式定位一致，`{"a": 1, bad}` 报在 `bad` 而非下一行 `}`）。
  - 尾逗号：对象/数组最后一个成员后的 `,` 合法（含跨行）；至少要有一个成员（`{,}`、`[,` 仍非法）。
  - **裸值**（`bare_word`）：无引号连续标识符词；`true`/`false`/`null` 关键字与 Python 风格 `None`/`True`/`False` 归类为对应标量（`None`→null），其余一律按字符串（`BILLING_SUCCESS`→"BILLING_SUCCESS"，含关键字前缀如 `tru`）。数字开头不进此分支——number 优先且保持严格（`01`/`1.` 仍报错）。
- **parser.rs**：`string()` 引号参数化（`"` 路径行为不变，`'` 共用同一循环），`value()`/`key()` 新增分支；**span 语义不变**——字符串节点 `start..end` 仍覆盖原始文本（含原始引号），树定位/表格定位零影响。
- **formatter.rs span 保真重排（2026-10-15 修订）**：格式化**只重排空白，不改写数据**——`write_node` 容器结构重新生成（缩进/分隔符/键序按源顺序），标量节点一律输出原文切片：单引号串保持单引号、`None` 保持 `None`、裸词不加引号、原始数字写法（`5.80`）与 `\uXXXX` 转义写法逐字保留。键为结构性字符串，统一以双引号 JSON 串重发。**嵌套展开**：字符串值内容为合法对象/数组时 `parser::parse` 子树递归展开（子树内部同样保真，`expandable_literal` 判定）；压缩不展开。手写 parser 拒绝但 serde 接受的罕见输入（孤立代理）回退 serde 规范化路径；双失败返回 serde 错误行列。`expand_nested`（Value 版）已删除。
- **detector.rs 同步宽松**：顶层结构扫描与 `consume_value` 单引号与双引号同权（单引号串内假括号不算结构）；候选验证与 `make_candidate` 改用 `parser::parse`（与载入共用同一语法）；缺括号 kv 补全键只放开**单引号**——裸键作启发式键会放大日志误报，不参与补全（裸键完整结构走结构扫描 + parse 校验）。
- **行为收敛**：格式化宽松回退与加载共用同一 parser ⇒「已加载但格式化失败」的场景不复存在（`{"a":"x\x01y"}` 裸控制字符原是两 parser 分歧点，现已一致）；format/minify 对任何已加载文档必成功。

## 5. Rust 端架构

```
src/
├── main.rs        # Tauri 入口、命令注册
├── parser.rs      # 带 span 的 JSON 解析器（宽松：单引号/裸键/尾逗号）：一次遍历产出 节点树 + 字节区间索引
├── formatter.rs   # 格式化 / 压缩 / 去转义 / 嵌套 JSON 递归展开
├── detector.rs    # JSON 探测：顶层片段扫描 / 转义还原 / 缺括号补全（2026-10-13 新增）
├── table.rs       # 数组→表格：列并集计算、行分块、多值过滤
└── state.rs       # AppState：原文(String) + 解析树 + span 索引，Arc<RwLock> 全局缓存
```

|---|---|---|---|

| `get_children` | node_id, offset, limit | NodeDto[]（含父链回退用） | 树懒加载 |
| `locate` | node_id | Locate（行列区间） | 树→原文 |

| `node_text` | node_id | String（span 切片） | 复制节点值 |
| `format_text` | indent, unescape | FormatOut（含重载后 rootId） | 格式化（含去转义+展开） |

| `table_create` | node_id | TableInfo（id/columns/rowCount/path） | 转表格（任意节点） |

| `get_rows` | table_id, offset, limit | Row[]（含 nodeId） | 表格浏览分块 |

| `table_export` | table_id, path, values, col | Result<String> | 导出 xlsx |

### 性能策略汇总
1. 解析、格式化、过滤全部在 Rust 端（后台线程），前端零阻塞。
2. 树/表格一律虚拟渲染 + 按需分块取数，前端内存中常驻的只有可见窗口数据。
3. span 索引一次解析、全期复用（树定位、原文定位共用）。
4. 目标指标：100MB JSON 解析 < 1s；树滚动、表格过滤全程 < 16ms/帧。

## 6. 错误处理

| 场景 | 处理 |
|---|---|
| 非法 JSON（严格与宽松均失败） | 错误行列 + 原文位置波浪线；不清空已加载内容 |
| 拖拽非 .json 文件 | 提示但尝试按文本加载（内容合法即可） |
| 解析超长字符串/深度 | 递归深度上限 512，超限报错提示 |
| Rust 命令异常 | 返回结构化错误，前端 toast 提示 |
| 表格失效（编辑后旧表） | **黄色警告**（⚠ 区别于真错误的红色），面板转隐藏 + stale |

## 8. 不做的事（YAGNI）

- 不做 JSON Path 查询、JSON diff、JSON Schema 校验（后续可加）。
- 不做编辑后写回原文件（原文可编辑仅作用于会话内解析，另存由表格导出承担）。
- 不做跨平台打包优化（先保证 Windows 可用）。
- 已裁剪：复制/另存工具栏按钮（由表格复制/导出承担）、load_file Rust 直读（大文件 IPC 优化为后续项）、fs 写权限收窄。
